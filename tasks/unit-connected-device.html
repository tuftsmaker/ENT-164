Track · planned

Connected Device

A device on the network: it joins WiFi, exposes data, and calls an API — the AI-and-connectivity half of the course, from Week 6 through Week 11.

Not available yet 4 tasks planned Signed off by a TA
This track is not open yet. The tasks below are what it will contain, written down so the shape of it is clear. The videos have not been recorded and the checks have not been built, so nothing here can be submitted or signed off.

Why this track

Weeks 6, 10 and 11 build a smart light, then sensing and visualisation, then AI-backed devices. It is the least file-checkable part of the course and the part students find hardest to know when they are finished — which makes written criteria more valuable here, not less.

What it will contain

Planned

Get the device on the network

(to record) credentials, the MAC address, the class registration step

Evidence: the script plus the device's address

Would check: the code connects and retries rather than assuming success

Planned

Serve a page from the device

(to record) the ESP32 as a web server

Evidence: the script and a screenshot of the page on a phone

Would check: the handler is a real route; the page renders without a client library

Planned

Show a reading from the world

(to record) sensor to data to a readable value

Evidence: the script and a screenshot showing a live value

Would check: the sensor's pin is an input; the value is scaled to real units

Planned

Reach an outside API

(to record) keys, requests, and what to do when the call fails

Evidence: the script, and a note on where the key lives

Would check: no key hardcoded in the script; the call has a failure path

Then: Demonstrate the round trip

Show it working with a TA present: the device answers, or the API responds. Most of this track's evidence is a demo rather than a file, and that is deliberate.

What it needs first

Accept that the strongest evidence here is a demonstration, not a file. The code checks are real but narrow — no hardcoded keys, a failure path, a sensible pin — and a TA watching a round trip is what actually settles it. Expect this track to lean harder on the human step than the other three.
