Using the ESP32-WROVER microcontroller and provided components, you will design and build a fun electronics project by partnering with AI to generate your code. Create something that interests you, makes you smile, or seems cool to build. This assignment teaches you how to effectively communicate your ideas to AI tools and iterate on solutions; a critical skill for modern makers and creators.

Learning Objectives

  • Describe electronics projects clearly to AI assistants
  • Follow AI-generated wiring instructions to connect components
  • Evaluate and test AI-generated MicroPython code
  • Troubleshoot issues through iterative AI conversations
  • Build confidence creating with technology, regardless of coding background

Before You Begin

Before starting this assignment, make sure you have:

  • Complete Electronics Kit: You should have received your electronics starter kit. Reach out to the instruction team if anything is missing.
  • Thonny IDE installed and MicroPython deployed to ESP32 Device: Thonny must be installed on your laptop and MicroPython must be deployed to your ESP32 device. Follow these instructions if you need to complete this setup.

Project Requirements

Technical Requirements

Your project MUST include:

  1. At least ONE input device (sensor, button, potentiometer, etc.)
  2. The ESP32-WROVER microcontroller for processing
  3. At least ONE output device (LEDs, display, motor, buzzer, etc.)
  4. AI-generated MicroPython code that you've tested and refined

Process Requirements

  • Document your AI conversations (share chat links)
  • Test and iterate on AI-generated code at least twice
  • Explain in your own words what the code does

The AI-Assisted Making Process

Step 1: Brainstorm Your Project with AI

Not sure what to build? Ask AI to help you brainstorm.

Download Part list.jpg and attach it to your initial prompt, then use this brainstorming prompt:

I'm a student working on an electronics project using MicroPython on an ESP32-WROVER microcontroller.

Based on the components available in the attached parts list, can you suggest 5-10 fun, 
creative, or interesting project ideas that I could build in one week? 

I'm looking for projects that:
- Use at least one input (sensor, button, etc.)
- Use at least one output (LED, display, motor, etc.)
- Are beginner-friendly
- Could be fun, silly, useful, or cool to build

For each idea, briefly explain what it would do and which components I'd need.

Pro tip: Look through the suggestions and pick something that excites you. You can also tell the AI about your interests (music, games, art, etc.) and ask for ideas related to those.

Step 2: Continue the Same Chat to Get Wiring & Code 

IMPORTANT: Keep using the same conversation. The AI will remember the parts list and your chosen project.

In the same chat, continue with:

I want to build [the project idea you chose]. Can you tell me:
1. How to wire these components to the ESP32 (which pins to use)
2. MicroPython code to make it work
3. Include comments explaining what the code does

Pro tip: Since you're continuing the same conversation, the AI already knows what components you have and can give you better, more specific help.

Step 3: Wire It Up

Follow the AI's wiring instructions:

  • Connect components to the GPIO pins the AI recommends (Remember GPIO pin numbers are written on the board)
  • Double-check your connections before powering on
  • Take a photo of your wiring for your documentation

Step 4: Test and Iterate in the Same Chat

Keep the conversation going. When something doesn't work:

  1. In the same chat, describe the problem: "The LED doesn't turn on" or "I get an error message that says..."
  2. Share any error messages exactly as they appear
  3. The AI will remember your project and help you fix it
  4. Test the new version

Pro tip: The AI remembers everything from your conversation, so it can give you better help as you go.

Deliverables

AI Prompting Tips for Success

DO:

  • Keep everything in one chat: The AI will remember your parts, your project, and your previous questions
  • Attach the parts list image at the start: Let AI see what you have available
  • Describe what you want clearly: "I want the LED to change colors based on distance"
  • Share error messages completely: Copy the entire error text from Thonny
  • Ask for explanations: "Can you explain what this line does in simple terms?"
  • Request step-by-step help: "Break this down into smaller steps"

DON'T:

  • Start a new chat for each question (you'll lose all the context.)
  • Manually type out all the component names (attach the image.)
  • Say "make it work" without explaining what's wrong
  • Skip testing between iterations
  • Be afraid to ask "dumb" questions. AI doesn't judge.
  • Give up after the first try. Iteration is the key.

Example Complete Conversation Flow

You: [Attaches parts list image from Canvas] "I'm a student working on an electronics project. Based on these components, can you suggest some fun project ideas? I'm interested in music and interactive things."

AI: [Provides 5-10 project suggestions]

You: "I love the idea about the distance-based color changer. Can you tell me how to wire the ultrasonic sensor and RGB LED to the ESP32, and give me the MicroPython code?"

AI: [Provides wiring instructions and code]

You: "I wired it up like you said and uploaded the code, but the LED stays off. I checked my wiring twice. What could be wrong?"

AI: [Provides debugging suggestions - remembers your project and wiring]

You: "That worked. Now can you modify the code so the red LED blinks when something is super close instead of staying solid?"

AI: [Provides updated code - remembers everything from earlier]

Note: All of this happens in ONE continuous conversation.
