The brain

Meet the ESP32-WROVER

A powerful, small controller with onboard wireless and camera.

Specs

  • Dual-core 32-bit microprocessor, 80–240 MHz
  • 520 KB SRAM · 8 MB PSRAM · 4 MB flash
  • 2.4 GHz Wi-Fi and Bluetooth 4.2 LE
  • Onboard camera, LEDs, and code uploader
  • Memory card slot and GPIO pins

What it controls

Motors through the driver, servos, joystick, potentiometers, sensors, and displays — the brain of your robot.

Breadboard basics

How the breadboard works

No soldering — push parts and wires into the holes and they connect.

Rows

Each row of five holes is connected horizontally, and the center channel separates the two sides.

Power rails

The vertical rails along the edges carry 5V, 3.3V, and GND to every row.

Pin rows

Your ESP32 plugs into the GPIO extension board: any of the horizontal holes in a pin's row connects to that pin — for example, pin 34.

First program

Make an LED blink

Type it in Thonny (or ask AI for it), then run it on the board.

blink.py

from machine import Pin
import time

led = Pin(2, Pin.OUT)

while True:
    led.on()        # Turn LED on
    time.sleep(1)   # Wait 1 second
    led.off()       # Turn LED off
    time.sleep(1)   # Wait 1 second

Challenge

Can you make it blink faster or slower?

Inputs

Knobs, sticks, and sensors

Your robot reads the world through inputs — here's how two common ones wire up.

Potentiometer

  • Left pin → GND
  • Middle pin (wiper) → ESP32
  • Right pin → 3V3

KY-023 joystick

  • GND → GND
  • +5V → 3V3
  • VRx (X-axis) → ESP32
  • VRy (Y-axis) → ESP32
  • SW (button) → ESP32

Outputs · servos

Move an arm with a servo

The SG90 micro servo rotates about 180° — perfect for arms, gates, and grippers.

Servo wiring

  • Brown / Black → GND
  • Red → 5V
  • Orange / Yellow → ESP32

On the robot

Servo 1 and Servo 2 wire up the same way — match the colors, not the memory.

ENT-164 · Intro to MakingClass 5 · Electronics12

Outputs · motors

Spin the wheels with the L298N

The driver is the muscle: the ESP32 sends signals, the L298N sends power to the motors.

L298N wiring

  • 12V → battery pack
  • 5V → logic power
  • GND → common ground
  • IN1, IN2 → ESP32 (left motor)
  • IN3, IN4 → ESP32 (right motor)
  • OUT1, OUT2 → left motor (red, black)
  • OUT3, OUT4 → right motor (red, black)

Your robot's wiring map
