Add your class tools to opencode

About 2 minutes
You only do this once

Your class has a set of tools that live on the class website — things like the wiring-diagram maker we use in class. This page adds them to opencode. Open opencode first, the same way you always do; it doesn't matter which project you have open. You don't install anything, and you can't break anything — you just ask opencode to do it for you.

1

Copy this sentence into opencode

Click in opencode's message box (the same box you type questions in), then copy and paste this whole sentence:

Copy and paste this
Add my class skills to opencode: https://tuftsmaker.github.io/ENT-164/skills/

Press Enter and let it work. It takes a few seconds.

2

If it asks for permission, say yes

opencode may ask something like "Can I change your settings file?" or "Can I run this command?" — that's normal. Click Allow or Yes.

Not sure? It's only changing opencode's own settings, not anything on your Mac. Nothing is deleted, and you can undo it by asking opencode to remove the class skills again.
3

Quit opencode and open it again

This part matters — the new tools only appear after opencode restarts.

  1. Quit with ⌘+Q (or opencode menu → Quit).
  2. Open it again the same way you always do.
4

Try it out

Type this into the message box and press Enter:

Try asking
Draw me a wiring diagram for connecting an LED to my ESP32

If it works, you'll get back a colored picture of the breadboard with the wires drawn on it.

If it doesn't work

What you seeWhat to do
opencode says it can't reach the website Check you're connected to wifi. The class tools live online, so it needs internet the first time.
Nothing new happens after restarting Ask opencode: "do you have the maker skill?" — it will tell you either way.
Still stuck Show your instructor this page. Nothing you did is broken, and it's quick to fix.
You never repeat this. The class tools update by themselves when your instructor changes them.
